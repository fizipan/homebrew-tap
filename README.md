# Homebrew tap

Casks for [Buku Token](https://github.com/fizipan/buku-token) and [Pantau](https://github.com/fizipan/pantau).

```bash
brew install --cask fizipan/tap/buku-token
brew install --cask fizipan/tap/pantau
```

Upgrade with `brew upgrade --cask <name>`. Each project's README explains what it does and how it's signed.
